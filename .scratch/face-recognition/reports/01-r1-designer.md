## 自截自改回路

本票产物是文档,没有可构建的页面产物,所以回路跑在「签字版参照图」上:凡文档里写的数,都要能在图上指到位置,指不到就不写。

1. 看图:`mock-desktop.png`(1440x1000)与 `mock-mobile.png`(390x844)整张读图看过一遍。
2. 放大核对两处关键claim:
   - 右上角峰值区(裁 x930-1440 / y70-240,放大 2 倍):`peak 1.33 Mbps` 与标题 meta `RVM1 · H.264-style hybrid`、折线右端同一条右边线;虚线在折线上缘,尖峰贴线不过线。
   - 手机 FACE REGISTRY(裁 x0-390 / y620-844,放大 2 倍):提示行之后才是 FACE REGISTRY,输入框与 `REMEMBER FACE` 等高,状态行 7px 圆点 + `Saved as Alice Ng, 3 frames averaged`。
3. 自改一轮(审计发现并改掉的 7 处):
   - 12px 例外写少了:跟踪标签也是 12px,原稿只列 OSD 与峰值角标两处;
   - `--fs-label` 升档范围写窄了:≤560px 时分区标题、meta、状态行、主按钮、顶栏 `EIE4428` 一并升 14,不只是「标签」;
   - 片段日期属 500/15px mono,原稿误归 sans 正文档;
   - 三个填充色的对比度原稿是估的(1.2 / 1.5 / 11.9),实算为 1.17 / 1.33 / 12.22;
   - 圆角例外里「告警框 2px」错了:`.bbox` 与 `.alarm` 是直角,2px 是 ROI;
   - 390px 控件排布原稿写成「两列」,与截图不符,实为每个字段一条三格行(标签 + 下拉 + 按钮),`Export metrics` 独占整行;
   - 跟踪标签衬底原稿写 60%,实为 `#000000b8` 即 72%。
4. 补了三条与仓库现状挂钩的可执行约束:读数空值用 `-`(现行页面是 `&mdash;`,与长破折号禁令冲突)、字体只用系统栈(测试钉住远程资源禁令)、既有 DOM id 全保留并写明三处迁移(`#m-codec` 进标题 meta、`#m-rec` 进 TRANSPORT、`#src-label`/`#time-label` 进顶部 OSD、`#view-label` 转 sr-only)。

- 层级:对得上。画面最大面积、遥测右栏 460、分级靠 600 字重与 `--text`/`--text-2`/`--muted` 三档色阶,没有靠放大字号堆层级;文档把这条写成硬规则(§1 末尾、§10 第三条)。

## 与设计指南的口径差(按卡要求写进报告)

- 指南把 dashboard / 密集产品 UI 列为范围外,本页正是这一类。只取对面板仍成立的部分(单一强调色、禁纯黑纯白、字号阶、圆角一致、无长破折号、状态齐全、数据不造假),不套用 hero / bento / 图片资产 / eyebrow 等落地页规则,已在文档开头写明。
- 双模式:指南要求亮暗都做,签字版是单暗色(现场投影)。文档 §10 明确「单暗色,要亮色另开票」,没有偷偷做半套亮色。
- 断点:指南建议 <768px 折叠,签字版用 ≤900px 单列 + ≤560px 换标签档。以签字版为准,文档按 900 / 560 写,并单列 390 的顺序。
